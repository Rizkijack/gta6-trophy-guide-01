# GTA VI Trophy Guide & Tracker

Offline web app tracking all 55 PlayStation 5 trophies for Grand Theft Auto VI: official names, descriptions and grades, progress saved in localStorage, export/import, filters by kind and grade, spoiler mode, roadmap to platinum, and cited per-trophy guides.

## Run it

node serve.ts -> http://localhost:8080
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

## Features

- Checklist of all 55 trophies with official name, description, grade, kind badge, missable flag, progress counter.
- Trophy detail panel with guide, steps, missable warning, roadmap stage, clickable sources.
- Roadmap view grouped by stage with counts.
- Filters: kind, grade, missable-only, fast search.
- Spoiler toggle hiding story trophy names/descriptions until earned.
- Export/import progress to a file.

## Sources and citations

Guides are written in our own words and cite named guides with URLs shown beside each guide. See RESEARCH.md.
